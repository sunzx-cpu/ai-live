# 快速开始 - 语音开播功能

## 🚀 Windows 用户（推荐）

### 1. 打包主程序

```bash
npm run build:win64
```

打包完成后，在 `build/` 目录获得：
- `ai-live-0.0.1-win.zip`（主程序，50-150MB）

### 2. 用户部署流程

#### 步骤 1：解压主程序

用户将 `ai-live-0.0.1-win.zip` 解压到任意位置，例如：

```
D:\ai-live\                 # 用户自定义位置
├── ai-live.exe            # 主程序
├── resources/
└── extra/                 # 不包含 AI 服务
```

#### 步骤 2：安装 VSA 语音服务

**重要**：主程序不包含任何 AI 服务，需要单独安装！

1. 从技术支持获取 `vsa.rar`（约 10GB）
2. 将 `vsa.rar` 解压到 `extra\vsa\` 文件夹
3. 确保解压后的文件直接在 `vsa\` 文件夹下（不要嵌套）

#### 步骤 3：启动应用

1. 双击 `ai-live.exe`
2. 点击顶部"AI服务器" → 选择"本地语音服务" → "启动服务"
3. 选择主播（在头部区域）
4. 选择脚本
5. 点击"语音开播"

✅ **完成部署后即可使用！**

## 💻 macOS 开发者

### 方式一：跳过本地服务（推荐）

1. 在 AI 服务器设置中选择"云端AI服务器"
2. 专注于 UI 和业务逻辑开发
3. 需要测试完整功能时，使用 Windows 环境

### 方式二：安装完整 VSA 服务（可选）

1. 获取 `vsa.rar` 并解压到 `extra/vsa/`
2. 安装 Python 依赖：
   ```bash
   pip3 install flask flask-cors flask-apscheduler flask-login flask-wtf pyyaml
   ```

⚠️ **注意**：AI 模型可能无法在 macOS 上运行（需要 CUDA）。

## 📋 功能说明

### 语音开播流程

```
用户解压 zip → 解压 vsa.rar 到 extra\vsa\ → 双击 ai-live.exe
    ↓
选择"本地语音服务" → 点击"启动服务"
    ↓
服务检查 → 如未安装 VSA 则提示："VSA 服务未安装，请将 vsa.rar 解压到 extra/vsa/ 文件夹"
    ↓
选择脚本 → 选择主播 → 点击"语音开播"
    ↓
循环读取片段列表话术 → 调用 VSA 生成音频 → 播放
```

### 关键功能

- ✅ **绿色版（便携版）**：解压即用，无需安装，可放在任意位置
- ✅ **自动服务管理**：开播时自动检查并启动 VSA 服务
- ✅ **主播切换**：支持多个主播模型
- ✅ **循环播放**：无限循环播放片段列表话术
- ✅ **队列管理**：预加载 5 个音频，确保流畅播放
- ✅ **暂停/继续**：支持暂停和继续播放

## 🐛 故障排查

### VSA 服务启动失败

**错误**："VSA 服务未安装"

**解决**：
1. 检查解压后的文件夹下是否有 `extra\vsa\` 文件夹
2. 检查 `extra\vsa\` 文件夹是否包含：app.py、py310\、data\ 等
3. 重新解压 vsa.rar 到正确位置

### VSA 服务启动超时

1. 首次启动需要 20-30 秒加载 AI 模型，请耐心等待
2. 检查端口 23456 是否被占用
3. 运行 `extra\kill23456.bat` 停止残留进程

### 找不到主播模型

1. 检查 `extra\vsa\data\models\` 下是否有模型文件夹
2. 每个模型文件夹必须包含 `config.json` 和 `.pth` 文件
3. 查看 `extra\vsa\data\models\README.md`
