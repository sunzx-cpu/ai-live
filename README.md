

# AI直播管理系统 (AI Live Boot)

## 项目概述

AI直播管理系统是一套基于Spring Boot 2.6.6构建的无人直播管理软件，采用前后端分离架构设计。系统提供完整的直播项目全流程管理能力，支持脚本化内容管理、智能互动响应以及多租户数据隔离，满足企业级直播运营需求。

系统基于成熟的renren-fast快速开发框架构建，整合了Apache Shiro安全框架与JWT认证机制，提供Web管理端和移动APP端双接口支持，具备良好的扩展性和可维护性。

## 技术栈

### 后端技术

系统采用业界主流的Java技术栈构建，确保系统的稳定性、可维护性和高性能表现。

核心框架采用Spring Boot 2.6.6版本，配合MyBatis-Plus 3.3.1实现数据持久化操作。数据库选用MySQL 8.0.28，提供可靠的数据存储能力。安全方面采用Apache Shiro 1.9.0结合JWT Token进行双重认证保障。连接池使用Druid 1.1.13，提供高效的数据库连接管理。缓存层支持Redis集成，可根据实际部署环境选择性启用。

开发环境要求JDK 1.8及以上版本，构建工具采用Maven 3.x版本。

### 辅助技术

系统集成了多种辅助技术以提升开发效率和系统功能，包括阿里云短信服务、阿里云OSS对象存储服务、定时任务调度组件、API文档生成工具Swagger等。这些组件共同构成了完整的直播管理生态系统。

## 核心功能模块

### 直播项目管理

直播项目是系统的核心业务单元，每个项目代表一个独立的直播配置方案。项目模块提供完整的项目生命周期管理能力，包括项目创建、信息编辑、列表查询、数据统计等功能。

系统支持多项目并行管理，不同用户可以独立管理各自的直播项目。项目与用户之间通过userId建立关联关系，实现多租户数据隔离。每个项目可以关联多个直播脚本，形成完整的直播内容体系。

### 直播脚本管理

直播脚本模块负责管理直播过程中使用的文案内容，支持富文本格式的脚本编辑功能。每个脚本可以设置独立的名称和内容，脚本名称在同一项目范围内需要保持唯一性。

系统提供脚本的增删改查接口，支持批量导入导出功能。脚本内容可以关联到具体的直播项目，通过项目ID进行关联查询。脚本模块是实现智能直播内容管理的核心组件。

### 直播片段管理

直播片段是对脚本内容的细粒度拆分，将完整的脚本内容分解为多个可独立控制的片段。这种设计使得直播内容更加模块化，便于灵活组合和调整直播流程。

每个片段包含独立的名称和内容字段，可以关联到指定的脚本。系统提供按脚本ID查询片段列表的接口，便于快速获取某个脚本下的所有片段内容。片段化管理使得直播内容的组织更加清晰有序。

### 智能互动管理

互动管理是AI直播系统的核心特色功能，包含关键词互动和动作互动两种机制。

关键词互动模块允许用户设置特定关键词，当观众发送包含这些关键词的消息时，系统自动触发预设的回复内容。关键词支持精确匹配和模糊匹配两种模式，可以满足不同的互动场景需求。

动作互动模块定义了直播过程中各种动作类型及其对应的回复内容。管理员可以配置不同的动作响应规则，实现丰富的直播互动效果。两种互动机制相互配合，构建完整的智能互动体系。

### AI配置管理

AI配置模块提供对大语言模型服务的统一管理和配置能力。系统支持多种AI服务提供商，包括OpenAI、阿里云千问、百度文心一言以及Ollama等私有化部署方案。

每个AI配置包含服务商类型、API地址、模型名称、API密钥等关键参数。系统支持配置启用禁用状态，可以针对不同项目配置不同的AI模型参数。此外还支持提示词模板管理，包括系统提示词、用户提示词和助手提示词的灵活配置。

### AI知识库管理

知识库模块提供向量化知识存储和检索能力，使AI能够基于特定领域知识进行回复。系统支持知识条目的增删改查批量操作，同时提供关键词搜索和相似问题匹配功能。

知识库支持Excel批量导入导出，便于大规模知识数据的快速录入和备份。每个知识条目包含问题、答案、关键词和排序权重字段，支持灵活的检索策略配置。

### 许可证管理

许可证模块实现商业授权管理功能，包含许可证包、订单、激活码和设备绑定的完整业务流程。系统支持生成激活码、验证激活状态、管理设备绑定关系等功能。

许可证包定义不同的产品版本和授权策略，订单记录用户的购买信息，激活码用于验证用户身份，设备绑定确保授权安全使用。系统还提供到期检查定时任务，自动监控许可证有效期状态。

### 商户管理

商户模块实现多租户架构下的商户信息管理，每个商户拥有独立的数据空间和配置参数。商户信息包含商户名称、状态、激活密钥、到期时间、注册信息等字段。

商户与用户之间存在一对多的关联关系，同一商户下的用户共享商户级别的资源配置。系统支持商户禁用激活、密钥激活、密码重置等管理操作，确保商户级别的访问控制。

### 公共大屏配置

公共大屏配置模块提供直播公屏显示参数的统一管理，包括直播URL、弹幕内容、互动间隔、自动回复等参数设置。该模块支持启用或禁用各项互动功能，满足不同直播场景的配置需求。

配置项涵盖文字回复、弹幕间隔、静默模式、GPT互动、知识库回复、重复发言处理等多个维度，提供灵活的公屏行为控制能力。

### 用户管理

用户模块负责系统用户账号的完整生命周期管理，包括注册、登录、信息维护等功能。用户与商户之间存在归属关系，用户的操作数据通过merchantId实现逻辑隔离。

系统支持基于JWT的安全认证机制，用户登录后获取Token凭证，后续请求通过Token进行身份验证。用户模块还支持短信验证码登录方式，提供多样化的身份认证选择。

## 系统架构

### 分层架构设计

系统采用经典的分层架构设计，从上到下依次为Controller层、Service层、DAO层和Entity层，各层职责清晰，耦合度低。

Controller层负责处理HTTP请求和响应，分为Web端接口和APP端接口两个子模块。Web端接口路径以"/biz"开头，提供完整的后台管理功能，需要Shiro权限验证。APP端接口路径以"/app"开头，提供精简的移动端API，采用JWT Token认证。

Service层实现业务逻辑处理，包含接口定义和实现类两部分。业务服务接口定义规范，实现类处理具体业务逻辑。对于基础数据操作，Service层直接继承MyBatis-Plus提供的IService接口和ServiceImpl实现类。

DAO层负责数据访问操作，通过MyBatis-Plus自动生成基础的CRUD操作。对于复杂的查询逻辑，系统提供自定义的SQL映射文件，位于resources/mapper目录下。

Entity层定义与数据库表对应的实体类，使用注解配置表名、字段映射和主键策略。实体类实现Serializable接口，支持序列化存储和传输。

### 权限控制体系

系统构建了完善的权限控制体系，实现基于角色的访问控制（RBAC）模型。

Web端采用Apache Shiro框架进行权限管理，通过@RequiresPermissions注解标注需要特定权限才能访问的接口。Shiro配置类负责配置安全管理器、过滤器和Realm，实现认证和授权的完整流程。

APP端采用JWT机制进行身份认证，通过@Login注解标注需要登录验证的接口。JWT过滤器拦截请求并验证Token有效性，解析用户身份信息后注入到请求上下文中。Token生成和解析工具类封装了JWT标准操作，确保认证过程的安全可靠。

系统还实现了多租户数据隔离机制，通过userId和merchantId字段实现用户级和商户级的数据分离。业务查询默认过滤当前登录用户的数据，确保各租户数据互不干扰。

### 数据源管理

系统支持多数据源动态切换能力，可以根据配置连接多个数据库实例。默认使用主数据源，通过@DataSource注解可以指定方法或类使用特定的数据源。

动态数据源配置采用AbstractRoutingDataSource作为路由目标，根据上下文选择实际的数据连接。数据源配置信息通过application.yml文件管理，支持灵活的环境切换。

### 缓存机制

系统集成了Redis作为高性能缓存层，提升数据访问效率和系统响应速度。缓存工具类封装了常用的缓存操作方法，包括String、Hash、List、Set、ZSet等数据结构的操作。

缓存key采用规范化的命名规则，避免key冲突和数据混乱。系统配置类提供RedisTemplate的Bean定义，支持序列化和反序列化配置。

### 统一响应格式

所有API接口返回统一封装格式，通过R类实现。R类继承HashMap，定义了success、error等静态工厂方法，返回包含状态码、消息和数据的标准响应结构。

分页查询结果通过PageUtils工具类封装，包含总记录数、页大小、当前页、数据列表等信息。这种统一的响应格式简化了前端处理逻辑，提高了接口的一致性和可维护性。

### 定时任务管理

系统集成了定时任务调度功能，支持基于Cron表达式的任务调度和管理。定时任务相关代码位于job模块，包含任务定义、任务调度、任务日志等功能。

任务实体包含任务名称、Cron表达式、任务参数、状态等字段，支持暂停、恢复、立即执行等操作。任务执行日志记录每次运行的详细信息，便于问题排查和性能分析。

## 接口文档

### Web管理端接口

Web管理端接口提供完整的后台管理功能，主要服务于系统管理员和运营人员。所有接口都需要登录认证，并根据用户权限进行访问控制。

直播项目管理接口组支持项目的增删改查操作。列表查询接口采用分页方式返回项目数据，支持按名称搜索筛选。单个项目详情接口返回项目的完整信息，包括创建时间、关联脚本数量等统计数据。

直播脚本管理接口组提供脚本的完整生命周期管理功能。脚本支持富文本内容存储，可以关联到指定的直播项目。接口提供Excel导入导出功能，便于批量管理脚本内容。

互动管理包含关键词互动和动作互动两个子模块。关键词互动接口支持关键词的增删改查，可以设置关键词对应的回复内容。动作互动接口定义动作类型及其响应规则，支持灵活的互动配置。

用户管理接口组实现用户账号的创建、信息修改、状态控制等功能。用户与商户存在归属关系，数据查询自动过滤当前商户范围。

### APP移动端接口

APP移动端接口针对移动设备优化，提供精简高效的API服务。接口设计遵循RESTful规范，返回数据格式与Web端保持一致。

登录注册接口支持用户名密码登录和短信验证码登录两种方式。登录成功后返回JWT Token，后续请求通过Header传递Token进行身份验证。用户信息接口返回当前登录用户的详细资料。

项目相关接口提供直播项目的基本操作能力，包括项目列表查询、单个项目详情获取等。脚本和片段接口提供直播内容的查询功能，满足移动端直播控制场景的需求。

配置管理接口允许用户在移动端查看和修改个人配置参数，包括AI模型配置、互动规则设置等。

### 许可证接口

许可证接口提供商业授权相关的功能服务。套餐列表接口返回可用的许可证套餐信息，包括套餐名称、价格、功能特性等。订单相关接口支持订单创建、查询和状态更新。

激活接口实现许可证激活功能，接收激活码和设备信息，验证激活码有效性后将授权绑定到设备。激活状态查询接口返回当前授权的详细信息，包括有效期、剩余天数、设备绑定情况等。

## 配置说明

### 数据库配置

数据库连接配置位于application-dev.yml文件中，需要根据实际环境修改以下参数：

```yaml
spring:
  datasource:
    url: jdbc:mysql://localhost:3306/ai-live?useUnicode=true&characterEncoding=UTF-8&serverTimezone=Asia/Shanghai
    username: your_username
    password: your_password
    driver-class-name: com.mysql.cj.jdbc.Driver
    druid:
      initial-size: 5
      min-idle: 5
      max-active: 20
```

确保数据库实例版本为MySQL 8.0及以上，并创建对应的数据库实例和用户账号。首次部署需要执行项目提供的SQL初始化脚本，创建所需的表结构和基础数据。

### Redis配置

Redis为可选组件，当配置启用时系统将使用Redis进行缓存管理：

```yaml
spring:
  redis:
    host: localhost
    port: 6379
    password:
    database: 0
    open: true  # 是否启用Redis缓存
```

如果不需要使用Redis缓存功能，可以将open设置为false或直接不配置Redis相关参数。

### JWT配置

JWT认证相关参数配置如下：

```yaml
renren:
  jwt:
    secret: your_jwt_secret_key_here
    expire: 604800  # Token有效期，单位秒，默认为7天
    header: token   # Token传递的HTTP Header名称
```

secret参数用于Token签名验证，建议使用复杂的随机字符串。expire参数根据安全需求调整，生产环境建议设置较短的有效期。

### AI服务配置

AI大模型服务配置需要根据实际使用的服务商进行设置：

```yaml
ai:
  config:
    openai:
      api-key: your_openai_api_key
      base-url: https://api.openai.com/v1
    qianwen:
      api-key: your_qianwen_api_key
      base-url: https://dashscope.aliyuncs.com/compatible-mode/v1
```

系统支持多种AI服务商的灵活配置，可以为不同的项目配置不同的模型服务商和API密钥。

## 快速开始

### 环境准备

部署本系统前需要准备好以下软件环境：

确保服务器已安装JDK 1.8或更高版本，建议使用JDK 11以获得更好的性能表现。Maven 3.x版本用于项目构建和依赖管理。MySQL 8.0用于数据存储，建议分配至少1GB内存给数据库实例。如果启用缓存功能，需要安装Redis 5.0及以上版本。

### 数据库初始化

创建名为ai-live的数据库实例，然后执行项目resources/sql目录下的初始化SQL脚本。脚本会自动创建所有数据表并插入必要的配置数据和初始用户账号。

默认管理员账号为admin，密码为123456。首次登录后建议立即修改密码并完善管理员信息。

### 项目构建

使用Maven命令编译打包项目：

```bash
cd ai-live-boot
mvn clean package -DskipTests
```

编译完成后，在ai-live-admin/target目录下生成可执行的JAR文件。可以通过java命令直接运行，或配置为系统服务。

### 启动服务

执行以下命令启动应用：

```bash
java -jar ai-live-admin.jar --spring.profiles.active=dev
```

或通过Maven插件启动：

```bash
mvn spring-boot:run -Dspring-boot.run.profiles=dev
```

启动成功后，控制台显示应用启动日志。通过浏览器访问http://localhost:8080/ai-live-api进入系统，使用初始账号登录即可开始使用。

### Swagger文档

系统集成了Swagger API文档功能，访问http://localhost:8080/ai-live-api/swagger/index.html可以在线查看和测试所有API接口。文档页面提供接口说明、参数定义、请求示例等详细信息。

## 开发指南

### 新增业务模块

开发新的业务模块时，建议遵循项目既定的分层架构规范。首先在entity包中定义数据实体类，使用@Data注解启用Lombok的getter/setter生成，使用@TableName指定对应的数据库表名。

然后在dao包中定义Mapper接口，继承BaseMapper<T>获得基础CRUD能力。Service层定义接口类并创建impl包实现业务逻辑。Controller层处理HTTP请求，调用Service层完成业务处理。

各层之间通过接口进行解耦，便于单元测试和模块替换。返回结果统一封装为R类型，确保接口响应格式的一致性。

### 权限控制

新增接口需要控制访问权限时，根据接口类型选择合适的认证方式。Web端接口使用@RequiresPermissions注解指定所需权限，系统会自动进行权限校验。APP端接口使用@Login注解标记需要登录验证，获取当前登录用户信息请使用@LoginUser注解。

权限标识采用"模块名:操作名"的命名规范，如"biz:user:list"表示业务模块用户列表权限。建议为每个功能模块创建独立的权限点，便于细粒度的权限管理。

### 数据校验

实体类字段校验使用Hibernate Validator注解，常用校验规则包括@NotBlank非空校验、@Length长度校验、@Max/@Min数值范围校验等。Controller层方法参数前使用@Valid注解启用校验，校验失败时抛出BindException异常，由全局异常处理器统一处理。

### 日志记录

系统使用@SysLog注解记录操作日志，AOP切面会自动采集方法执行信息并保存到数据库。@SysLog注解支持value属性自定义日志描述内容，便于区分不同操作类型的日志记录。
